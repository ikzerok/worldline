# 只读对象候选检索（工具 0.29）

地图对象反查和标记绑定使用同一个 core `Catalog::search_objects_page` 接口，直接读取
已编译的不可变 `Catalog`。接口不读取磁盘、不编译 `Project`、不修改源码或展示文档，
也不解释查询语言。通用资料组合查询的名称/属性语义不因此改变。

## 匹配、身份和来源

输入是普通自由文本。core 对输入 `trim` 后使用 Rust Unicode `to_lowercase`，分别
对子串匹配对象的 display、完整 ID、kind 或该完整 `TargetRef` 的任一别名。空输入
匹配全部目录对象。保留地图原有名称、ID、kind 的 Unicode 大小写行为；新增别名
不能把同名对象合并，也不把字符串猜成引用。路径、正文、属性和地图几何不参与匹配。

结果逐项包含原 `CatalogObject` 的完整 `target={kind,id}`、display、file 和 line。
file/line 是对象的真实定义来源，命中别名不把别名声明位置冒充对象定义位置。返回顺序
按 `TargetRef`（kind，再 id）稳定排序；对象身份及顺序不依赖显示名称或目录收集次序。
使用者必须显式选择一个完整身份，不能因为名称相同或只有一条候选便自动绑定。

## 页与预算

`ObjectSearchOptions={offset,limit,max_candidates}` 默认是 `0,20,10000`。limit 必须
在 1–100；候选预算必须在 1–100000，沿用既有组合查询的默认预算和最大预算。
预算检查以完整目录对象数为准，超出时返回 `CandidateBudgetExceeded`，不返回部分页
或虚假的精确总数。缩小文字查询不能规避扫描预算，不在 UI 静默提高预算。

成功的 `ObjectSearchPage` 包含 items、精确匹配 total、请求 offset、实际 limit、
truncated 和 next_offset。`truncated` 表示当前页未包含全部匹配项（包含已在前页的项），
`next_offset` 仅在还有后续项时存在。offset 大于 total 返回 `InvalidOffset`；等于 total
合法并返回空页，无后续页。超大 offset 不发生算术溢出；无非法 limit 自动夹取。

总数只保证所给目录中的匹配数；Catalog 本身不证明源码全部可解析。调用方负责显示
编译错误导致的目录不完整状态。未加载/过期目录不能当成完整空结果。

## 编辑器消费与保护

地图两个入口均显示名称、完整类型/ID 和来源，显示当前范围与总数，并提供上一页、
下一页和收窄提示。每页最多显示 20 条反查或 8 条绑定候选；分页让后续对象可达。
UI 不再自行匹配名称/ID/类型/别名，不调用逐帧 `Project::query_catalog`。

候选缓存键包含工作区、当前编译/展示快照代次、输入和页。输入或来源代次改变即丢弃
旧候选、回到首页；翻页只计算新页。尚未加载显示不可用；源码编译有错误时，明确标记
只检索已解析目录、总数不代表完整作品。不可用或错误页没有可供点击的旧候选。

临时搜索绑定只在点击某个当前候选后建立。开始新查询或快照变化清除旧的临时选择，
要求重新确认，不自动套用同名对象。失效的临时身份作为待确认草稿保留，期间阻止新建落点
或保存当前标记；只有重选对象、明确“不使用对象引用”或取消表单才能解除。取消这类
表单同时丢弃其被阻止的新建落点与重试项，不得稍后以无引用标记复活。
已从既有标记载入的绑定属于作者草稿，保留其完整
身份；来源变化导致失效时必须明确提示，不得自动解绑或替换。取消表单仍取消整个未提交
草稿，保存/删除/落点继续经既有 core 命令。地图反查位置仍来自现有 MapIndex，保留
跨地图导航、隐藏图层确认、子地图行为与所有未提交草稿守卫。
