# 书稿检索与导航快照（工具 0.31）

语言默认 1.9、最高显式 1.13；不增加 DSL、文档版本或工作区能力。
本契约定义只读的整书检索。章节编排、运行顺序和世界时间仍相互独立。

## 唯一真源与草稿

`Project::manuscript_query_snapshot` 从同一 Project 缓冲和明确传入的按文件
WritingBuffer 生成不可变 `ManuscriptQuerySnapshot`。应用稿与显式编排草稿分别
标记；`ManuscriptQueryDraft` 含 expected_baseline 和完整 ManuscriptDraft。
草稿只投影，不应用、不保存，不推进撤销、Revision、存档或 RNG。
草稿基线失效、同文件冲突、重复草稿或不存在的书稿明确报错，不能悄悄退回应用稿。
未变化 WritingBuffer 不覆盖工程新稿。正文编译错误保留可识别编排与诊断，无法
确认的来源标为 unresolved，不把当前稿文字量伪装成应用稿统计。

已生成快照上的筛选与分页不刷新、不访问文件系统、不做磁盘保存基线预检。
生成快照复用既有只读 core 编译、注册路径身份与附件检查，可能读取相应元数据；
源码只能来自明确载入缓冲，禁止缺失源码回退磁盘，也不运行提交保存预检。
快照只说明已载入内容；外部刷新之后必须生成新快照。导航与提交各自保留既有即时校验；查询成功和
`complete` 不授权写入，也不承诺磁盘未变化。`preview_manuscript`、
`apply_manuscript` 的全部工程内容/Revision/磁盘/能力/未知字段保护不变。

## 查询与身份

核心 DTO 使用 schema_version 1，未知请求字段拒绝。范围为一个明确书稿，可选
一个真实 section ID 子树；不存在、非分节或歧义范围报错。text 对标题、稳定 ID、
摘要和目标字段做 Unicode 小写包含匹配，空白分隔词全部命中；status 对状态做
小写包含匹配，pov 对完整 kind/ID 和可确认显示名做小写包含匹配。三类条件交集。
不解释 DSL、正则或查询语言。重复标题/POV 名称不合并；真正身份是书稿 ID + entry ID。

所有筛选先作用于完整范围，再按 core 深度优先阅读顺序分页，单页 1–100 行。
新查询limit必须位于1–100；0、101或更大值明确报INVALID_LIMIT，不静默钳制。
旧ManuscriptIndex::page的历史limit钳制行为保持不变；offset超末页规则另见下文。
章节视图只返回命中章节；树视图额外返回祖先分节，明确 context-only。无筛选的
树保留空分节；折叠是个人视图，筛选时展开命中祖先。显示方式或筛选不重排原稿。
返回精确 recognized_chapters、matching_chapters、total_rows、offset、limit 和
next_cursor；recognized 仅指当前可识别项，结构不完整时不得声称完整书稿总数。
结果包括同快照父路径的 ID/标题、阅读顺序、摘要、状态、目标、POV及显示名、
来源四态与定位、静态统计；静态统计沿用 manuscript.md，不代表实际运行路线。

无法解析、未知能力、坏父链、成环、重复 ID 通过 complete=false 和原诊断呈现。
可识别项仍按安全恢复顺序可见；恢复路径标为不完整，绝不改写原稿。重复身份统计先遍历原JSON全部可读取string ID，即使某项kind无效或未投影仍计入；
合法项与坏kind项同ID时，合法项也标身份歧义，不能选中或作为分节范围。歧义 ID 行
只能只读展示，不能把同名或同 ID 的另一项当作当前作者位置。缺失来源不等于
没有章节；零命中也不等于没有问题。

游标绑定快照、范围、筛选、树/章节模式和折叠状态；其 offset 不可用于其他
快照或查询。变更任一依赖后旧游标报 STALE_CURSOR。明确 offset 可用于个人
视图恢复，超出末页时钳到最后有效页，并回报实际范围。查询错误是故事层失败，
不是 JSON-RPC 协议错误；错误 code/message 稳定，message 中文。

## 缓存和往返

`Project::manuscript_query_key` 覆盖根/入口身份、全部载入源码和展示文档字节、
墓碑、语言、能力/只读和活动源码集合、刷新代次、恢复状态，以及每个正文草稿
的文件/基线/代次/完整文本和每个编排草稿。不可只用当前章、数组长度或标题作 key。
key 中的路径按本机 `Path` 分量编码并保留分量边界；同一已载入路径的重复分隔符、
中间 `.` 及 Windows 普通路径的 `/`、`\` 分隔符写法不应单独造成缓存失效。
该编码不访问磁盘、不解析链接或折叠 `..`，非 Windows 文件名中的反斜线仍是字面字符；
分量保留非 UTF-8 原字节，Windows 前缀保留其种类和名称，不合并不同盘符、共享或
普通/设备路径。不改变工作区路径校验、文档身份或诊断原文。
缓存只复用只读结果；查询、显示页和正文投影分层，未变化帧不重新全书编译或
完整提交预检。失败结果也绑定同一 key；取消输入、丢弃草稿、重试和外部刷新均
按真实依赖重新判断，不能复用一次失败抹掉新输入。

编辑器保存个人筛选、模式、列选择、页/滚动和书稿/章节稳定身份；不写入作品。
标题可截断但完整身份/来源可查。进入正文、旁查、审稿再返回恢复原位置；若原章
被筛选、删除或身份歧义，明确说明并保留输入，不自动跳到同名替身。键盘上下
移动当前页真实行，Enter进入选中正文。窄窗通过可达的章节入口和横向/分页浏览
承载信息，不能把必要动作藏在整书长滚动底部。

## 机器消费

CLI 和 RPC 使用同一请求/响应 DTO，调用 core snapshot/query，不另写过滤、
层级、来源或计数语义。查询可消费已应用稿；明确传入编排草稿须绑定当前工程
基线。默认无未应用正文，进程中已有 WritingBuffer 的调用方可明确叠加。
路由与能力由 agent-protocol.md 统一登记。

### 请求预算与严格读取

RPC params业务请求（含project_id、query和全部drafts）最大4 MiB；CLI查询参数合计最大4 MiB，不截断草稿。查询text/status/pov每项
最多4096 UTF-8字节；书稿/分节/选中/折叠ID每项最多256字节；折叠ID最多16384项；
游标最多512字节。核心共享validate与JSON解析器；JSON重复键、未知请求字段及
draft嵌套target_ref/pov未知字段均拒绝。预算只限制查询入口，不删除原始作品内容。
业务响应payload最大4 MiB，RPC外层沿现有协议封套；超限返回明确BUDGET_EXCEEDED，不把截断页作为完整结果。
业务过期或不完整页面返回ok:false，可携带原样partial page；已解析JSON的形状/预算输入错误为CLI退出码2或JSON-RPC -32602；raw JSON无效或重复键沿既有全局解析规则返回-32700。CLI业务失败退出码1；成功退出码0。

### 外部元数据与原稿不完整保护

缓存依赖key与实际snapshot内容key分离。Project载入/明确refresh时复用既有
外部文件可读性观测，记录新增/删除/可读性与边界失败；每帧只读取已记录标记。
该独立观测由Project候选/clone共享，restore保留最新观测，不写入作品、不进入
content_baseline，不推进既有undo外部源码代次。相同成功no-op refresh不改观测；
失败刷新不能证实依赖不变，必须使旧可信缓存失效，并在新页明确不完整原因。
宿主不经过native refresh而更新附件时，编辑器recompile明确失效只读缓存。

新snapshot内容key额外绑定实际产生的诊断、附件available/resolved_path及章节
来源投影；即使未先refresh而重新构建，也不得接受属于旧元数据结果的cursor。
这不声称缓存期间磁盘持续不变，也不替代来源跳转与提交的即时守卫。

若原书稿有MAN001/005/006/007/008结构诊断，显式typed编排草稿返回INVALID_DRAFT；
不能由from_index只提取可识别项，再借只读投影把未理解的原坏项“修复消失”。
原始字节和全部诊断保留，正常写入端既有拒绝守卫保持不变。
