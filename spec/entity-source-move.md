# 单实体声明安全移源（工具 0.24）

本功能仅整理一个已有 `entity` 声明的存放位置，不新增 DSL，不改变默认语言 1.9、
最高显式语言 1.13、实体稳定 ID、运行语义或能力。人物、事件、片段、目录、资源和
批量对象迁移不属于本动作；整文件移动仍使用既有 `move` 契约。

## 请求与对象身份

在既有 [源码生命周期](source-lifecycle.md) 中增加：

```json
{"operation":"move_entity","id":"north_lighthouse","to":"设定/地点.wl"}
```

Rust 为 `SourceLifecycleRequest::MoveEntity { id: String, to: PathBuf }`，仍由
`preview_source_lifecycle[_classified]`、`apply_source_lifecycle[_classified]`
及完整计划应用入口处理；CLI/RPC消费同一 DTO，不建立另一套解析规则。

`id` 是当前编译目录中唯一、明确的 entity 稳定身份。源文件由 core 实际声明位置
解析，不能由 UI 或机器调用方猜测。目标须是当前已跟踪、非删除、活动的工作区 `.wl`
源码；可先通过既有新建源码动作建立它。不隐式创建文件、不自动激活归档源码、不
修改 include 或加载顺序。原生相对路径、大小写/链接/工作区边界沿用生命周期规则。
源和目标是同一规范文件时返回明确无变化计划（`changes` 为空），不建立撤销或保存
动作；仍检查当前请求的合法性和保护状态，不把路径别名作为另一份文件。

## 精确原文范围

core 通过当前语言版本的正式 lexer/parser 定位声明；只能移动一个顶层 entity 及其
明确所属的正文/description、property、同行注释和块内注释。保留该范围内的原始
UTF-8 字节、空白、换行与 CRLF；不重新序列化资料来替代原文。声明前独立注释不
自动猜作对象所属；相邻声明、它的注释和独立分隔空行不得被误带走。预览必须让作者
看到准确的源删除与目标插入边界。跨界块注释或其他无法明确证明的边界拒绝整次操作。
目标插入在文件顶层末尾；需要分隔换行时明确投影新增字节，不能与末尾注释/声明粘连。
源声明没有末尾换行、混合Unicode/emoji、长行及目标末尾无换行分别有回归覆盖。

范围从 entity 声明物理行首开始，到最后一个正式 description/property 行结束，包含
其终止换行；期间的空行和缩进块内注释保留。末尾紧邻且有块缩进的纯注释行可属于
该块，遇独立空行或顶层注释立即停止；不吞掉之后的分隔空行。跨度内出现不能明确
归属该块的顶层独立注释、注释跨越删除边界或目标末尾未闭合块注释，均拒绝。
位置证明逐条映射真实删除/插入产生的文件和行偏移，不清空位置字段或全局重排数组。
声明顺序中仅该 entity 的存放位置可以改变；其它声明/语句顺序必须保持。

## 等价证明

当前活动稿和候选均须无编译错误，清单/已登记创作文档的能力与可写状态有效。
source/target活动身份、源码加载顺序、默认入口及语言版本/能力必须保持；不通过
新增 include、调换加载顺序或升级语言“修好”候选。

完整 entity 资料和全部正式身份引用必须相同。只允许移源导致的真实来源位置变化；
其他显示名、description、属性值/类型、引用目标、关系端点、标签/附件/状态所属、
正文链接、schema绑定和重复引用次数不得改变。不能只比较运行指纹、编译是否成功
或显示名。正式路径相关值及相对资源如受声明位置影响，须由 core 证明解析目标及
原始资源字节保持，否则明确拒绝；不猜改普通文字或未知扩展字段。作为原始附件的
源文件/目标文件若字节改变且不能保持资源等价，拒绝整笔操作。

运行 fingerprint 前后必须相同；移源可以改变内容基线和作者来源，不得改变 state
所属实体身份、分支行为、入口或普通 Story Save 的兼容条件。这不授权绕过跨版本
runtime_version/schema/指纹守卫，不迁移旧 trace/checkpoint/save。

## 计划、守卫与事务

复用 `SourceLifecyclePlan` 的 request、source_path、destination_path、membership、
前后运行指纹、entry、load_order、资源证据与 changes。非空计划只改变源和目标两个
源码缓冲；每侧使用真实UTF-8字节半开范围、原文和前后上下文投影，不能用UI猜行号。
计划摘要必须绑定完整当前内容/刷新代次/保存基线与工作区库存、相关资源内容及能力。
库存包括未注册普通文件的路径与原始字节；其新增、删除、改名或同路径内容变化
使旧计划失效。库存内容按非链接普通文件有界读取，单文件最多64 MiB、总计256 MiB，
超过预算则明确拒绝，不省略大文件后继续证明。
预览后源、目标、其余内容或库存/能力发生变化时，旧计划必须拒绝或明确过期。
修改计划公开字段、精确范围、上下文、目标或摘要不能授权提交。

预览、取消、非法/不支持对象、同文件无变化、越界、非活动/已删除文件、错误稿、
未知能力、外部变更、过期或伪造计划均不得部分改写任何缓冲。可取消入口在准备及
提交前检查取消；失败保留原始数据。成功一次替换私有候选，调用方只记一次Project
快照，可一次撤销/重做。应用不自动保存；保存仍使用既有可恢复journal，不宣称
跨文件物理原子写入。失败分类沿用生命周期的有类型原因，不解析中文消息判断权限。

## 作者界面约束

界面明确写“移动实体资料声明”，显示名称、稳定ID、当前来源和受支持范围；目标
只列合法活动源码，完整路径可查看。预览先说明对象/去向，再展示源删除与目标插入，
关键确认/取消保持可达，长中文路径或窄窗口不能把动作挤走。未应用表单或正文输入
必须保留且阻止混入操作，不隐式提交或清空；作者明确处理后重新预览。

应用后按稳定实体身份定位新来源，不能将原源文件中其他对象的历史位置全部改到目标。
既有对象阅读/查询/引用保持可回源；撤销/重做后重新取得当下真实来源。状态区准确
区分已应用未保存、已保存和零变化；错误给出原因及下一步，不能把未证明当作已完成。

## 验收边界

回归覆盖声明/相邻内容与注释、UTF-8/CRLF、同源无变化、多个合法目标、状态所属实体、
全部正式引用、静态与运行证明、重复编译稳定摘要、CLI/RPC真实预览/应用及坏请求。
磁盘外改、源/目标/库存/能力变化、取消和篡改须证明失败前后字节/缓冲一致。
原生路线包括选实体、目标、预览、应用、一次撤销重做、保存重开与新来源导航；
完整导出保留隐藏目录和未引用文件。未做的平台/浏览器/物理输入法验收须分别标明。

同源无变化的机器 apply 返回 `applied:false,saved:false`，不触发保存；其余机器应用
继续先一次内存提交，再走既有 journal 保存，并如实区分提交与保存失败。
