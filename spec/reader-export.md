# 静态阅读包

静态阅读包用于发布选定的公开内容，不是工作区备份。它只包含作者在一次选择 DTO 中明确列出的资料对象、书稿章节和附件；正文引用、书稿来源引用、地图可见性、标签、附件关系和其他链接都不会自动扩大公开范围。完整备份仍按 [workspace.md](workspace.md) 导出全部普通文件，包括未引用附件、隐藏文件、说明文档和 `.agent` 创作资料。

## 选择清单

core 的 `ReaderExportSelection` JSON DTO 版本为 1：

```json
{
  "schema_version": 1,
  "site_title": "公开阅读站",
  "objects": [{"kind": "event", "id": "opening"}],
  "manuscripts": [{"id": "book", "chapters": ["chapter_one"]}],
  "attachments": ["cover_art"]
}
```

对象使用 `TargetRef`，只接受已解析且受支持的公开对象；`file`、任意路径和 `asset` 不接受在 `objects` 中，附件必须以清单中的 asset ID 单独授权。书稿章节按每册单独列出，数组顺序同时决定阅读顺序；空章节清单无效。章节标题和摘要是该章节选择的一部分，章节的来源对象只有在 `objects` 里也被选中时才会成为可访问页面。未选来源统一显示“未公开内容”，不输出目标 ID、显示标签或源路径。正文对象上的显式链接也只解析到本次选择中的页面或附件。

选择不是传递闭包。每一项都是明确的公开决定；排除清单仅出现在作者预览响应，不写入生成包。预览可列出未选对象、章节、附件和工作区路径，供作者逐项核对。站点页面、manifest、搜索索引、资源文件名与链接只使用站点标题、选定内容和生成的安全路由，不包含排除清单或源路径。

## 预览与应用

`Project::preview_reader_export` 仅读取当前 Project 缓冲，不刷新、保存、迁移或推进基线。它检查编译结果、选择范围、书稿结构、章节来源、附件可用性和当前存储事务，并生成 `plan_digest`。摘要绑定公开选择、Project 内容基线和已选附件字节；所以源码、书稿或已选附件在预览后变化会使摘要失效。它是过期检查标记，不是密码学签名。

`Project::build_reader_export` 重新计算计划并要求调用方提供匹配摘要，返回相对路径到文件字节的映射，不写工作区。`Project::export_reader_site` 在原生环境发布到一个工作区外、尚不存在的新目录；目标父目录必须已存在。写入先放在同级暂存目录，验证每个输出路径，再重命名发布。过期计划、已有目标、越界目标、编译错误、不可用附件、文件系统错误或超出限额时，不覆盖已有目标。

CLI 使用：

```text
wl reader-export preview <工程目录或入口> --selection-json '<JSON DTO>' --json
wl reader-export apply <工程目录或入口> --selection-json '<JSON DTO>' --plan-digest 摘要 --out <新目录> --json
```

preview 返回 `plan`（含 `included`、作者专用 `exclusions`、内容基线和摘要），不创建输出目录。apply 必须重传相同选择和摘要；过期返回 `STALE_PLAN`，其他发布错误返回 `EXPORT_FAILED`。JSON-RPC 方法见 [agent-protocol.md](agent-protocol.md)。

## 生成内容和安全边界

包包含站点入口、对象和书稿索引页、选中内容页、静态 CSS、站点 manifest、仅使用公开内容的搜索 JSON/JS，以及单独授权的附件。输出路由用生成序号命名，不使用来源 ID、标题、文件名或工作区路径。运行时不执行故事分支和条件；字面量文本保留，动态表达式显示为通用省略提示，效果和作者状态字段不公开。书稿的 POV、目标、状态、目标说明、原始 JSON 与源位置不会复制。

链接、脚本、样式表和搜索资源全部为包内相对路径；搜索结果用 `textContent` 创建，不把搜索内容当作 HTML。资源拒绝 HTML、SVG、脚本、样式和其他活动内容格式，只接受受限图像、音频、视频扩展名。生成过程不下载远程资源，也不添加远程字体、脚本或其他网络依赖，包可离线打开。

选择上限为 500 个对象、100 本书稿、5,000 个章节和 128 个附件。每个附件上限 16 MiB，附件总量上限 64 MiB，完整包上限 128 MiB。无效书稿、只读书稿、章节来源不可解析、选择重复、越界/不可读附件或活动附件格式都会使预览失败，不会静默放宽公开边界。

完整工作区备份的内容、路径与未引用文件保留语义不变；阅读包不得替代、裁剪或重定义 `export_files`、另存工程或 ZIP 备份。
