# 创作模型补全（v1.9）

v1.9 采用以下创作模型：

1. 叙事锚点成为独立 ID 对象，可关联角色、事件和状态变化，记录叙事意义；与当前状态集合分工。
2. 身份权限统一为状态标签，不再维护独立权限集合。旧作品的权限归到世界下名为“叙事身份”的状态，迁移保持行为。
3. 保留执行路径分支汇合与回环；时间 follows 仍是禁止环的偏序。

## 状态集合的增删

`become STATE with TAGS` 替换全部内容；新增 `become STATE add TAGS` 和 `become STATE remove TAGS`，分别按集合增加、移除标签，不触及其他标签。同值、重复增加或移除不存在标签也可记录明确动作。三种操作均可用于事件过程及效果块；编译出处必须带操作类型，演练历史保留前后集合。

## 旧权限迁移

旧 `grant P`、`revoke P`、`perm(P)`、事件 `perm P` 仅为迁移输入，统一转换为叙事身份状态的 add/remove/has。与原 after 合并时使用 and 并保持原表达式优先级；注释、文本中的同名词和字符串内容不误改。标签、状态和缺失时补建的世界使用防冲突 ID；已有唯一世界不重复创建。转换覆盖所有引用文件、嵌套条件与效果、文本插值，重复迁移不再修改。

编译旧源时仍可读取，核心将其归一到同一状态模型；编辑器对工程缓冲提供迁移，原文件在保存前保持不变。导出使用归一后的源文件。不含旧权限写法的工程不改写。运行时不能保留第二份可独立变化的权限真相；旧机器字段如需兼容，必须由状态集合派生。旧存档需要显式兼容处理，不能静默重置权限或放宽任意指纹不匹配。

## 独立锚点

`anchor_def ID as "名称"` 在顶层定义锚点，可在缩进块内写 `description "叙事意义"`。`anchor_link ID KIND TARGET` 关联完整对象，KIND 可为 character/event/state/anchor，支持跨文件引用。状态变化通过“关联状态＋关联事件”索引相应动作，不复制状态内容，不用会因编辑漂移的行号充当长期身份。

锚点进入通用对象目录，允许 mark/attach。索引提供关联对象及其来源，状态变更出处，按角色和事件反查锚点；未知 ID 与重复锚点声明为 A217。已有正文 `anchor "名称"` 的手动演练记录继续有效，不将每条历史记录自动定义为独立锚点。独立锚点是作者定义的叙事意义对象，本身不驱动运行与时间顺序，不改变存档指纹。

## 关系图和阅读

分析输出后续连接的条件上下文与目标准入要求；条件只表达显式分支与准入，不宣称运行必然到达。不新增自然语言冲突检查。

跨文件正文概览按故事线与编排序号集中阅读完整事件，保留正文结构和条件、不求值、不产生第二份正文。顺序仅供阅读，不生成 follows。
