# 查询范围与世界资料巡检

## 1. 作者意图与真源

已有组合查询或共享 saved query → 同一编译与已注册地图缓冲快照的完整命中 → 地图位置与正式关系巡检 → 真实资料/源码编辑 → 返回原查询、分页与视图位置 → 显式清除临时范围。

本合同不新增语言、持久集合文件、展示预设字段、公开选择、关系推断或 runtime 状态。所有筛选、身份、结果计数、地图绑定和正式关系来自 core。普通文字提及不属于正式关系，地图几何包含、线段相交、颜色和图层不生成世界事实。

## 2. 一次构建、不可变查询快照

`CatalogQuerySnapshot` 在一次 `CompileResult` 上复用现有查询校验、条件解释和稳定排序。快照持有查询指纹、Project 内容基线、候选预算、完整命中及诊断。候选默认 10,000、最高 100,000；超过预算、取消或无效查询返回错误，不提供伪装完整的部分集合。

快照的分页方法只切片完整命中，返回新增 owned-diagnostic `CatalogSnapshotPage`，继续使用已有 `CatalogQueryCursor`。游标仍使用 schema 1，保留 offset、page_size、max_candidates、query_fingerprint 和 snapshot；旧 Project 查询与续页 API 兼容。快照续页须验证完整游标身份。零命中只指此查询范围；编译错误使来源不完整，不能声称作品为空。

## 3. 同快照世界投影

`CatalogScopeSnapshot` 与查询快照共同构建，一次编译后按同一当前 Project 的已注册地图缓冲建立 `MapIndex`，不调用会再次编译的 `Project::map_index`。持有 typed 对象身份、资料来源、命中、逐处地图绑定和独立正式关系。一次对象多图、多标记、旧 placement 和 scene node 均保留各自地图/图元身份及类别，绝不按显示名合并。

投影携带 schema、内容基线、完整命中数、已放置命中数、未放置命中数、匹配绑定数、未解析绑定数、来源完整性、诊断和各预算。未知格式/能力、缺失地图和无效引用以不完整/未解析说明；缺失来源不推断成确定未放置。可解析的只读地图仍可巡检，不能据此获得编辑权限。装饰图元保持正常画布显示，不作为查询命中。

投影对象（含未解析正式端点）最多 100,000，地图绑定最多 100,000，正式关系最多 100,000，诊断最多 10,000；这些是硬上限，查询候选预算可更低。每个追加项先计数并通过有界流式 JSON 计量，累计完整 DTO 编码最多 32 MiB，禁止先建立无界 JSON 再检查。超限拒绝构建，不返回截断的假完整范围。传输输出遵守既有 Worker 32 MiB JSON 预算，输入遵守 10,000 文件/128 MiB 工程快照预算。大型构建的取消点覆盖候选与投影循环；底层一次编译/地图解析期间不可抢占的阶段需如实说明。

## 4. 正式关系局部巡检

关系巡检由明确焦点开始，1–2 跳，最多 250 节点与 500 边。每个节点标明 query match、context-only 或 unresolved；上下文节点不是查询命中，也不增加命中总数。边保留稳定关系 ID、关系类型、真实 from/to、类型方向与源码位置。只使用独立 typed 正式关系；不混入文字提及或把旧无稳定 ID 的显示句柄变成持久关系。

分页/截断是局部关系显示预算，不能改变作者的完整查询范围。超出局部预算时明确截断与续查入口；无关系与未解析分别显示。关系投影消费同一冻结数据，不读取当前磁盘，不混用编辑后的端点。

## 5. 编辑器生命周期

执行为显式动作。原生在后台线程构建，WASM 使用现有同源 Worker；不在空闲帧编译、解析地图或读磁盘。每个任务携带提交查询、预算、内容基线与本地代次；快速改条件、重开、取消、切换工程或来源变化后，旧结果不得替换新输入。取消保留条件和已有作者稿；不显示部分结果。分页只访问已完成不可变快照。

进入临时范围保存之前的个人地图位置、网络状态与查询位置。范围列表显示全部命中数量并有界分页；地图按每个绑定定位，不修改坐标、隐藏/锁定图层或持久属性。隐藏/锁定位置仍列出并说明；遵守现有导航与草稿保护，不为定位自动显示图层。

对象/源码动作沿已有合法身份导航，保留未应用写作、表单、地图与网络输入。地图/网络中持续提供返回查询和清除范围。返回保留同一查询、页码和已访问视图位置；清除恢复进入前的个人视图，若身份/来源已改变则使用已有安全恢复规则说明跳过项，不猜测同名替身。

编辑、外部刷新或 WASM 新导入后，旧投影标为过期；不混用旧坐标与新内容。作者显式刷新重新构建完整范围并显示旧/新命中数量。查询不会自动保存，不改变公开授权与 runtime 指纹。

## 6. 验收

覆盖超过一页的完整命中、零匹配、同名异 ID、一个对象多图/多标记、未放置、未解析、context-only、未知地图能力、隐藏/锁定图层、正式方向、两跳截断、陈旧游标、取消/快速切换、返回来源与明确清除。纯浏览前后 Project 内容基线与运行指纹保持相同。

固定大资料与 5,000 scene node 夹具分别记录冷构建、热分页、地图定位、关系焦点 p50/p95/max 和取消/内存边界；原生/WASM分别核验。五种布局、十七配色、长中文、窄窗与 200% 缩放复用既有视觉与焦点合同。测试/实测与未测边界应分别记录。

## 7. 机器接口

`wl catalog-scope <目录或入口> --query '<CatalogQuery JSON>' [--max-candidates N] [--offset N] [--page-size N] [--focus '<TargetRef JSON>'] [--relation-options '<RelationQueryOptions JSON>'] [--json]` 只读生成完整 scope、当前结果页和可选焦点关系。它不接受旧查询 cursor；完整冻结 scope 已一次返回，分页调用 core 快照切片。

RPC `catalog.scope` 必须且只能提供 `project_id` 或 `path`，必需 `query`；可选 `max_candidates`（默认 10,000）、`offset`（默认 0）、`page_size`（默认 50）、`focus` 和 `relation_options`。`project_id` 分支只读取该会话已经应用的 Project 缓冲，不调用 `refresh`、不加载外部改稿，也不隐式恢复保存事务；`path` 分支仍用 `open_read_only`，存在未完成事务时只读拒绝。外改需要调用方另行显式调用既有 `project.analyze` 等刷新动作后再查询，本方法不能声称实时磁盘状态。构建仍只编译一次。返回 `ok`、`schema_version:1`、`workspace_revision`、`scope`、`page`、`relations`；成功响应附 `source_mode`（`applied_project_snapshot` 或 `read_only_path_snapshot`）、`refreshed:false` 与 `conflicts:null`，表示本只读方法没有主动检查/处置磁盘冲突。`scope` 包含完整有界 typed 对象/绑定/正式关系和 owned 诊断；`relations` 仅为选定焦点的局部页。未知参数类型或缺少/冲突的入口是 JSON-RPC -32602；无效查询、预算、IO 或陈旧业务状态是 `ok:false`，错误沿用 core QueryError code。反序列化 scope 不创建写权限；此接口无任何写入方法。

机器请求参数总编码最多 4 MiB；RPC id 在复制前流式计量，最多 3072 字节，超额用 null id 的小型 -32600 响应。RPC/CLI 的完整 JSON 行（包含 envelope、id、重复的结果页及换行）最多 32 MiB；超额明确 `BUDGET_EXCEEDED`，不输出部分范围。独立路径入口使用 `Project::open_read_only`，不借浏览动作恢复/保存事务。编辑器画布轮廓最多 500 个当前地图绑定，明确显示该绘制预算；完整对象/绑定仍可分别分页巡检，视觉预算不改变命中集合。

新不可变查询/范围构建只编译 Project 已跟踪源码缓冲，禁止对未跟踪 include 进行磁盘回退；缺失来源显示 A105 与不完整状态，旧 `Project::query_catalog` 契约不变。`Project::catalog_scope_observation_key()` 仅返回上次显式载入/刷新记录的内存观测键，不读取磁盘，也不是写入授权。消费者把该键与提交时的查询、内容版本共同绑定；附件变化、保护观测变化或观测失败即使未改变正文内容基线，也使缓存和晚到任务失效。真正无变化的刷新不使键变化；冻结快照自身不随外部文件更新。

只读回归必须在会话打开之后注入真实可恢复 journal：`catalog.scope(project_id)` 保留全部磁盘文件、journal 原始字节与已应用 Project 内容；单独的控制工程通过显式正常打开确能恢复同一有效 journal。外部改稿后未显式刷新时继续返回会话旧快照，显式 `project.analyze` 后才返回新快照。
