# worldline 术语表

**版本：**1.9。本文定义当前语言与创作模型的术语。具体语法、生命周期和结构检查以本目录其他规范为准。

| 术语 | 定义 |
|---|---|
| **世界工程** | 一个入口及其引用的全部源文件共同组成的世界观、人物与事件集合；完整文件夹可以交付和重新编译。 |
| **事件节点** | 世界中的一件事，有稳定 ID、可选简述、正文、所属故事线与可选约束；不要求成为某条演练路径的必经步骤。 |
| **对象 ID** | 对象在其类型命名空间内的稳定身份，全工程共享；显示名称、排序位置和所在文件不代替 ID。事件名即事件 ID。 |
| **故事线** | 事件的单一叙事归属。不同故事线可以并行创作；执行跃迁、时间先后和标签引用分别建模。 |
| **森林结构** | 对故事线分组的历史术语，不代表执行图必须为树；执行图允许环，跨故事线执行跃迁使用显式漂流。时间偏序可以跨故事线。 |
| **序号** | 图中的编排序号；可以显式用 at 指定，否则按声明顺序生成。序号不承担稳定身份，也不表示运行顺序。 |
| **时段** | 一组事件的时间范围；只表达分组，不解析日期或时长。范围内可同时存在局部有序链和无序事件。 |
| **先后关系** | follows 明确指定的时间偏序；不代表事件已访问，不代替准入要求，不产生执行跃迁。 |
| **人物（字段）** | 事件的角色 ID 集合；with 可省略，省略表示空集合。不是自由文本人名。 |
| **角色** | 有稳定 ID、姓名、属性、关系及关联事件反向索引的完整对象；可以成为多个状态的目标。 |
| **身份权限** | 状态标签表达的准入凭据；旧权限统一迁移到世界下显示名为“叙事身份”的状态，不维护独立权限集合。 |
| **前置要求** | 事件进入条件；after 使用布尔组合，可查询 seen、has 等。旧 perm 归一为身份状态查询，与时间先后约束分离。 |
| **后续节点** | 从跃迁和选择推导的执行出口，不强制世界中的每条记录都必须具有出口。自然完成按运行语义结束。 |
| **事件简述** | 面向浏览的可选摘要，不替代正式正文。 |
| **事件内容** | 叙事正文与结构语句的混合表达，始终属于完整事件或场景，不独立寻址正文片段。 |
| **标签** | 指向完整对象的引用集合，可引用其他标签；支持去重与循环安全的递归查询。 |
| **状态** | 有独立 ID、指向一个完整对象（包括标签）、内容为标签集合的记录；一个对象可以拥有多个状态。 |
| **状态变更出处** | 按状态 ID 汇集各事件中的 become 替换/增加/移除操作及上下文，kind 区分动作；不是无序事件的唯一历史或当前事实。 |
| **状态历史** | 可选演练实际发生的状态操作记录，含操作类型及变更前后集合；同值动作仍可记录，随存档持久化。 |
| **效果** | 显式时机下的状态、人物或故事线变动，可有条件与叙事说明。身份变动使用同一状态模型；enter 在准入后，exit 在事件离开时，done 仅自然完成。 |
| **独立叙事锚点** | 由 anchor_def 定义、有稳定 ID 的意义对象，可关联角色、事件、状态或其他锚点；按关联状态与事件过滤变化出处，不复制状态真相。 |
| **演练锚点记录** | 正文 anchor、漂流等在运行时产生的按发生序记录；保留旧语义，不自动变成独立锚点对象。 |
| **后续条件上下文** | GraphEdge.contexts 中的显式条件与选择路径，以及 target_requirement 中的目标准入要求；不证明执行必然到达。 |
| **正文概览** | 从工程源缓冲集中展示跨文件事件正文与效果，不求值条件；阅读顺序不产生时间约束。 |
| **漂流** | 经 ->> 执行跃迁进入另一故事线并记录变化；不代替普通时间约束。 |
| **素材引用** | 将工作区内图片、音频或其他文件关联到完整对象；用户点击后使用系统应用打开。 |
