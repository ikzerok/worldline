# 当前稿查找与受控替换

查找是编辑器能力，不改变语言版本、运行指纹格式或工程必需能力。core 是字面匹配、正文范围、保护 token 和替换事务的唯一真源。

## 范围与匹配

提供当前文稿、已捕获选区、显式选择的工程文件。正文范围只消费正式词法器确认的普通正文、选项文字、disabled 静态说明、description 与 say spoken text；声明 ID、ref、表达式、稳定行 ID、装饰、演出备注和整个显式链接均不可替换。源码范围可查全部字节，但替换仍仅允许确认的正文片段；身份变更使用重命名入口。无法确认的无效片段只读查找，拒绝替换，不丢草稿。

匹配为非重叠字面量，支持区分大小写和整词。Unicode 按字符边界处理；不区分大小写逐字符 Unicode lowercase 比较，不做归一化或语言区域特例。整词边界是 Unicode 字母数字或下划线，中文连续字按一个词处理。空查询返回零命中。位置保存 UTF-8 字节范围，UI 转换字符光标。跨行匹配不跨保护片段。disabled 说明内的花括号与链接外形均为纯文字，允许字面替换但不改转义双字符。替换文字不能引入新语法、换行、引号或转义；修改后正式词法/内插检查必须仍保持正文身份与受保护 token，无法确认就拒绝。

工程查找将 Project 当前源码与每文件唯一 WritingBuffer 合并；同路径相同源只计一次，冲突重复草稿明确报错。未应用草稿覆盖同文件 Project 搜索文本。过期草稿可查但不可应用替换。

## 计划与提交

计划绑定工程完整内容基线、显式文件/选区、完整当前稿、每份 WritingBuffer 基线/代次、查询选项、替换文字及具体命中。预览列出路径、数量和修改前后片段。既有 `preview_search_replace` 仍预览全部命中；新增 `preview_search_replace_selected` 只接受作者明确选择的精确离散命中，支持同一文件、同一行的独立取舍。应用重新生成并核对计划，不信任调用方提交的替换范围。工作区未知能力、只读、未解决保存事务、磁盘外改、工程或草稿变化均拒绝，任何失败零修改。

当前稿替换只改变唯一 WritingBuffer，尚未应用内容继续是草稿；跨文件替换明确提交选中文件的当前稿，并用一个 Project 内存事务替换。成功不保存磁盘；撤销/重做也不保存。取消/关闭预览不改变工程或草稿。草稿替换有独立可撤销前后快照，后续输入使旧快照失效时拒绝覆盖。工程事务沿用 Project 撤销与刷新代次保护。

## 逐处选择与身份

`search_drafts` 返回的 `SearchMatch` 含 `identity: Option<SearchMatchIdentity>` 与 `context: Option<SearchContext>`。真实搜索结果两者均为 `Some`；其他只读导航可构造 `None`，但该位置不能授权替换。身份由 core 创建，字段不公开，所有命中以共享快照绑定工程精确原始内容、刷新代次、实际合并源、查询文字/选项/范围，以及有编辑的唯一 WritingBuffer 的基线、源字节与代次；不能仅凭行列、字节区间或列表下标重新制造选择。快照比较使用完整字节，不以非密码学内容摘要相等作为证明。刚为查看原文创建的无修改、零代次缓冲不改变实际搜索源或身份；发生过编辑的草稿即使恢复原文也不能复用旧代次。

`preview_search_replace_selected(request, drafts, selected)` 接收所选 `SearchMatch`，重新确认当前快照与每个 core 命中；空选择、重复、伪造、越界、受保护和过期选择全部拒绝，不静默丢项或重定位。源码范围同时含可替换文字与保护 token 时，可以明确仅选择前者；旧全部替换入口仍在任一命中受保护时拒绝整批。空查询搜索零命中，不产生可提交计划。替换包含查询词时仅操作原始离散集合，不搜索或递归替换新文字。

`ReplacePlan.hits` 为按请求文件次序、原源位置排序的实际选中集合；`changes` 为每文件完整安全候选，`occurrences` 为同一事务的逐处前后字节范围及有界上下文。应用使用同一选择方式重建计划并比较全部内容；修改公开预览字段不能获得写权限。改变查询、选项、范围、替换文字或选择集合须重新预览，旧计划不能被混入新提交。只查看原文再返回不丢弃有效审阅。计划本身不拥有 UI 的撤销历史。

## 有界真实上下文

`SearchContext.text` 是原源中真实连续子串；`source_range` 为整份源的 UTF-8 字节半开区间，`highlight` 为该子串内真实命中交集的 UTF-8 字节半开区间。替换为空时，修改后强调为真实零宽位置。省略号、行号和提示均由 UI 在源文之外绘制，不写入 `text`；CRLF、跨行、emoji 和组合字符不被归一化。旧 `SearchMatch.preview` 同步提供有界子串，不再为每个同一行命中复制整条无限长源行。

每处上下文最多 160 个 Unicode 标量、640 个 UTF-8 字节，通常给命中前最多 48 个标量，优先显示可完整容纳的命中；超长命中展示真实前缀并明确 `match_omitted_after`。`match_omitted_before` / `match_omitted_after` 描述命中自身是否越过窗口；`omitted_before` / `omitted_after` 对单行命中描述该物理行内容两端，对跨行命中描述整份源两端。边界不切断 UTF-8 字符，尽可能保持 CRLF 与 grapheme；病态超长字素簇需要标量级截取时以 `grapheme_clipped` 明示，不将截取声称为完整字素或完整命中。长行第 253 列及同一行不同命中均以各自真实位置取得窗口与强调。

搜索仍有最多 10000 命中的硬限，超过时明确报错；UI 应使限制内全部命中可达，可分页或使用有界滚动，不因渲染前 1000 项而留下不可见导航。UI 只消费 core 的保护标记、范围和上下文，不另写正文匹配或保护规则。

## 编辑命令与焦点

编辑菜单与平台快捷键共用命令：查找、工程查找、替换、上/下命中、撤销、重做。输入控件内优先 TextEdit 局部撤销，其他焦点使用最近有效编辑事务，不双触发。Enter 前进、Shift+Enter 后退。Escape 只关闭最上层临时界面并恢复此前焦点；不丢未应用文字。IME 活跃及当前帧输入法事件期间不消费这些快捷键。提示在编辑/撤销状态变化后失效，不把历史成功当作当前状态。

## 输入局部撤销与同稿同步

当相同输入控件的内容由另一正文/源码视图、替换事务、Project撤销或外部刷新改变时，编辑器先丢弃该控件不再对应当前原文的局部历史，并以当前稿建立新基线；不能让下一次输入撤销恢复到旧视图的过期整段内容。正常连续输入保留该输入框自己的Undo/Redo，Project事务历史独立保留。视图切换不复制第二份正文真源。
