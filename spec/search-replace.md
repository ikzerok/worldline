# 当前稿查找与受控替换

查找是编辑器能力，不改变语言版本、运行指纹格式或工程必需能力。core 是字面匹配、正文范围、保护 token 和替换事务的唯一真源。

## 范围与匹配

提供当前文稿、已捕获选区、显式选择的工程文件。正文范围只消费正式词法器确认的普通正文、选项文字、disabled 静态说明、description 与 say spoken text；声明 ID、ref、表达式、稳定行 ID、装饰、演出备注和整个显式链接均不可替换。源码范围可查全部字节，但替换仍仅允许确认的正文片段；身份变更使用重命名入口。无法确认的无效片段只读查找，拒绝替换，不丢草稿。

匹配为非重叠字面量，支持区分大小写和整词。Unicode 按字符边界处理；不区分大小写逐字符 Unicode lowercase 比较，不做归一化或语言区域特例。整词边界是 Unicode 字母数字或下划线，中文连续字按一个词处理。空查询返回零命中。位置保存 UTF-8 字节范围，UI 转换字符光标。跨行匹配不跨保护片段。disabled 说明内的花括号与链接外形均为纯文字，允许字面替换但不改转义双字符。替换文字不能引入新语法、换行、引号或转义；修改后正式词法/内插检查必须仍保持正文身份与受保护 token，无法确认就拒绝。

工程查找将 Project 当前源码与每文件唯一 WritingBuffer 合并；同路径相同源只计一次，冲突重复草稿明确报错。未应用草稿覆盖同文件 Project 搜索文本。过期草稿可查但不可应用替换。

## 计划与提交

计划绑定工程完整内容基线、显式文件/选区、完整当前稿、每份 WritingBuffer 基线/代次、查询选项、替换文字及具体命中。预览列出路径、数量和修改前后片段。应用重新生成并核对计划，不信任调用方提交的替换范围。工作区未知能力、只读、未解决保存事务、磁盘外改、工程或草稿变化均拒绝，任何失败零修改。

当前稿替换只改变唯一 WritingBuffer，尚未应用内容继续是草稿；跨文件替换明确提交选中文件的当前稿，并用一个 Project 内存事务替换。成功不保存磁盘；撤销/重做也不保存。取消/关闭预览不改变工程或草稿。草稿替换有独立可撤销前后快照，后续输入使旧快照失效时拒绝覆盖。工程事务沿用 Project 撤销与刷新代次保护。

## 编辑命令与焦点

编辑菜单与平台快捷键共用命令：查找、工程查找、替换、上/下命中、撤销、重做。输入控件内优先 TextEdit 局部撤销，其他焦点使用最近有效编辑事务，不双触发。Enter 前进、Shift+Enter 后退。Escape 只关闭最上层临时界面并恢复此前焦点；不丢未应用文字。IME 活跃及当前帧输入法事件期间不消费这些快捷键。提示在编辑/撤销状态变化后失效，不把历史成功当作当前状态。

## 输入局部撤销与同稿同步

当相同输入控件的内容由另一正文/源码视图、替换事务、Project撤销或外部刷新改变时，编辑器先丢弃该控件不再对应当前原文的局部历史，并以当前稿建立新基线；不能让下一次输入撤销恢复到旧视图的过期整段内容。正常连续输入保留该输入框自己的Undo/Redo，Project事务历史独立保留。视图切换不复制第二份正文真源。
