# 逆潮档案：逐处审阅与安全替换

此示例使用既有语言1.13，把世界资料、人物证词、可见锁定选择和两种结果放在同一作品中。示例故意保留一条尚未核实的证词；工具不判断它的真假。

## 打开与试玩

将本目录作为worldedit工作区打开，或运行：

```sh
wl check examples/selective-replace --json
wl play examples/selective-replace
```

先检查信封印信，再进入灯塔；分别选择保存证词或交给潮务局，可以走到两个不同结果。根文件保留入口，子目录源码由同一工作区加载。

## 只修改需要改的说法

假设作者决定把客观叙述中的“九扇窗”改成“窄窗”，但保留闻笙那句原始证词，以便继续审阅她是否说错。

1. 打开工程查找，输入“九扇窗”，阅读每条匹配附近的原文
2. 进入替换并输入“窄窗”；保留未选中的人物引文，明确选择其余需要修订的命中
3. 预览并核对实际选择的逐处前后差异；长行结果应能看见匹配词
4. 确认应用后，检查引文原字节仍在、只有所选叙述变化；可一次撤销/重做
5. 保存全部，关闭重开，再执行check和两条试玩路径

`property windows = 9` 是结构化资料值，不在普通正文替换范围中。要改它，使用资料/源码编辑并检查结果；替换不会暗改ID、引用、内插或其他受保护标记。全文相同文字也不意味着同一事实，是否修改始终由作者决定。

操作边界见[逐处审阅与替换](../../docs/selective-replace.md)和[core规范](../../spec/search-replace.md)。
