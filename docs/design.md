# 架构决策

worldline 使用 Rust 单一实现，分为 core（解析、分析和结构创作）、runtime（演练）、cli/agent（人机入口）。worldedit 是独立的 Rust/egui 仓库，只消费 core/runtime，禁止反向依赖。

源码是作者内容真源，分析快照是索引、诊断、执行图与时间偏序的唯一来源。编辑器通过核心草稿接口回写文本，失败回滚缓冲，不维护另一份人物卡或正文副本。

世界设定独立于某条播放路径。事件可有无序时间关系，follows 表达同一时段的无环偏序；执行分支允许汇合与回环。布局和阅读排序不产生时间约束。

状态是绑定对象的标签集合，独立锚点表达作者定义的意义，通过事件与状态 ID 反查变化出处。旧权限归一到世界叙事身份状态，保留精确旧指纹迁移，不建立第二份权限真相。

工作区目录是作品边界：递归发现全部源码，禁止外部引用，完整导出保留全部文件。CLI/agent 复用相同分析，但目前不控制运行中的编辑器 UI。语言契约以 spec 为准，历史设计和第三方研究不进入发行源码。
