# 需求清单与追踪矩阵

版本：0.2，待评审（0.2修订：M1矢量画布——WE-018 基础线面前移 M1，WE-014 验收按阶段拆分，栅格图层措辞）。此清单是需求编号、优先级和验收口径的唯一表；不是已完成任务列表。

## 1. 口径

P0 为首个可用版本及数据安全门槛；P1 为核心内容/关联能力；P2 为完整体验增强。阶段 M0=基线与契约、M1=地图展示闭环、M2=通用实体与网络、M3=内容体系与叙事关联、M4=高级展示与文件协作。优先级不表示用户已经批准排期。

每条需求同时提供所属仓库、来源任务、依赖和可观察验收结果。`T-需求编号` 是计划中的验收用例，不代表已经执行。建议的 PR 划分见 [实施计划](IMPLEMENTATION.md)，边界与数据见 [共同契约](../../../spec/presentation.md)。

来源任务取自用户修订报告第十二节，共21项；原报告涉及世界演化的前版不参与本清单。范围包括原有工程保存/交换，不增加面向其他平台的内容导出功能。

## 4. 更改管理

新增或变更需求时同时改本表的JSON源、生成表、PRD对应章节、架构契约与测试计划。不得只修改界面描述而不更新删除、保存或引用语义。范围变更中一旦出现模拟、状态随时间自动推进、人物自主行动，应拒绝归入本PRD。
