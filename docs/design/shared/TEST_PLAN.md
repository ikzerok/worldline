# 测试计划与验收证据

版本0.2（0.2修订：M1矢量画布负载、帧率M1记录不阻断、预算指向共同契约阈值登记）。这里描述产品落地后应执行的测试；本次没有运行Rust、桌面GUI或浏览器产品。独立设计文件验证结果见根目录`VALIDATION.md`，不能替代本计划。

## 1. 基线与环境

冻结worldline `dcb6479873f86b08354ba92b098dc260aa976624`与worldedit `b0955adcccd740d9b3b46cee1d0f503ad25f5257`。记录Cargo.lock实际版本、Rust工具链、OS、CPU、内存、GPU、浏览器完整版本、DPI和构建profile。

主验收平台：Windows桌面和WASM浏览器；其他平台仅声明实际做过的构建/验证范围。不要用原型脚本或仅cargo check替代GUI手势测试。

## 2. 验收数据集

D0：当前harbor-world及现有语言测试。\
D1：只有world、人物/tag和地图，无event的纯内容工程。\
D2：雾港总览图、城市图、灯塔、人物林舟、组织与历史资料，多标记指向同一对象。\
D3：包含正式关系、正文提及、同名词条和图形线的来源区别项目。\
D4：损坏JSON、越界路径、缺栅格图层素材、断链、未知schema、并发修改与保存中断。\
D5：1,000对象、3,000关系、500标记、数千矢量图元、2048×2048栅格图层及4096×4096边界图（仅桌面档）。

本包examples是契约样例和对象索引桩，不包含真实地图底图，也不是可直接在0.2.0打开的完整项目。D0–D5需在实现PR中建立真实工程夹具。

## 4. 纯函数与属性测试

Camera2D正变换后逆变换误差在选定容差内；指针中心缩放前后锚点屏幕位置不变；图层临时过滤无文件变更；拓扑查询不修改边集合；一次拖动取消零事务；多次JSON读取写回保留未知值；相同query输入产生稳定顺序。

对随机几何、层ID、对象ID和损坏JSON做边界测试。资源读取只用授权工作区，不通过map字段启动网络。已选热点优化必须与未经优化查询对照结果一致。

## 5. 性能目标与测法

目标数据D5；release构建；冷启动与暖态分别记录。至少多轮测量，报告P50/P95和最大值，保存原始样本。

| 指标 | 门槛（单源见[共同契约](../../../spec/presentation.md)第11节） | 备注 |
|---|---|---|
| 暖态局部查询 | P95≤150ms（M2起验收） | 包含筛选，不包含首次工程IO |
| 暖态资料切换 | P95≤200ms（M2起验收） | 使用同一快照，不重新扫描全部文件 |
| 地图交互帧 | P95≤33ms：M1记录不阻断，M2起为发布门 | 对应约30fps门槛，不用平均值掩盖卡顿 |
| 内存 | 解码/CPU缓存/GPU缓存分别受预算约束（平台分档） | 测换图和多次撤销后的释放 |
| 无修改浏览 | 共享写入次数=0 | 硬门槛 |
| 不相关内容污染 | .wl字节变化=0，运行指纹变化=0 | 针对纯展示编辑 |

若目标不满足，先做可见项裁剪、索引缓存和纹理复用，不首先引入新引擎。首版大图限制是边界，不是优化失败的掩饰；需要更大图再测独立方案。

## 6. 故障注入与人工场景

保存测试在准备、临时写、首次替换、中间替换、最后替换、日志提交、清理分别注入失败；并在恢复前引入第三方改动。浏览器模拟Storage拒绝/配额、下载取消、超大包；不能因UI动画结束就判为保存成功。

人工验证需要截图/录屏或步骤日志：高DPI、窄窗口、中文输入法、无中键设备、键盘定位、重叠标记选择、编辑/浏览切换、Esc取消、双端包往返。图例不能只靠颜色。

P0全部通过且旧测试无新增失败，才能发布M1；帧率/内存在M1为记录指标（随G1/G4原型出具实测），M2起按[共同契约](../../../spec/presentation.md)第11节作为发布门。M2–M4只声明实际实现和验证的需求。未知功能只读、安全边界、保存失败不覆盖、浏览无副作用为阻断项；不接受“以后再修”。
