# 从资料表批量导入与修订

世界资料表采用UTF-8 CSV。先选择一份资料表，再把每一列明确映射为身份、显示名、实体分类、实体描述或有类型的属性。无需编辑JSON；桌面工作台提供列映射和完整逐行预览。

1. 保留稳定身份列kind与id。kind填character或entity，同名对象不自动合并；同一kind+id重复行会阻断整批
2. 选择新增对象写入的既有活动.wl源码；旧对象仍改原文件
3. 每列必须映射或明确忽略。属性选择text、number、bool或ref；ref另外选择目标kind，单元格只填目标ID
4. 空单元格默认报错。可选“保留”，或仅文本字段选“空文本”。空格不等于空，0和false保持真实值；没有删除哨兵
5. 查看每行新建/更新/无变化/阻断、忽略列、真实字段前后值及运行指纹。引号内CRLF规范化为LF会显示数量。人物显示名或标量改动可能令旧演练存档不兼容
6. 一次应用全部有效行，工程尚未保存；一次撤销恢复整个批次。然后用普通保存全部落盘

所有字段都通过现有compiler/schema。缺少实体或引用能力时，请先在已有能力入口显式启用，再重新预览；导入不会暗升语言。无效基线工程须先修复。来源CSV、映射、工程缓冲或外部文件变化会使预览失效。

允许逗号、双引号和多行文本，双引号用两个双引号表示。原CSV最多2MiB、500数据行、64列、单格64KiB。UTF-8 BOM可读取，不猜GBK/TSV；孤立CR拒绝。text中的公式样式或HTML只是文字，绝不执行。

未映射属性、旧关系、注释、缩进、混合换行与其他声明保持原文字节。相同资料表再导入是无变化，不重复创建或重排。既有对象修改只使用字段补丁，不整块重写。

机器批次见 [CSV与DTO规范](../spec/catalog-import.md)。CLI的apply不加--save只改内存，进程结束即丢弃，输出saved:false；持久化必须明确--save。RPC先project.open、catalog.import.preview、catalog.import.apply，再显式project.save。
