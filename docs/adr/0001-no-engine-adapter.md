# ADR-0001：不提供游戏引擎适配器

- 状态：已决定（用户于 2026-09-26 明确要求“不考虑游戏引擎适配器”）
- 关联：CAP-09A / worldline#24、CAP-09C / worldline#27、CAP-09D / worldedit#28

## 背景与决定

CAP-09A 原先要求选定首个引擎、确定嵌入或离线导出协议，再实现试点。用户已排除游戏引擎适配器，因此本轮不选定 Godot、Unity 或其他引擎，不新增适配 SDK、引擎产物 manifest 或引擎加载样例。

CAP-09C 已按用户后续明确要求直接删除（GitHub 确认 HTTP 410），不能标为适配器已交付。适配器专属版本、资源失败、更新、缓存与存档兼容协议均不制定；没有运行原型，没有引擎集成验证，不把现有 CLI JSON 输出称为引擎集成。

## 保留范围与后果

core 继续是分析与内容解释的唯一真源，runtime 继续解释运行语义；现有 CLI/RPC、纯内容工程、保存和发布行为不变，不添加任何引擎依赖。

本决定不取消 CAP-09B 的稳定字符串与翻译往返工作。CAP-09D 中台词审阅、本地化及失败定位仍可独立实施；其引擎选择、适配器产物加载验收不再适用，不能为保留游戏面板强加引擎配置。

如未来重新提出引擎接入，必须重新立项和选型；此次排除不代表已验证任何引擎、版本或许可证兼容性。
