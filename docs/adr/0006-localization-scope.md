# ADR-0006：本地化字符串身份与翻译往返范围

- 状态：提案，待用户授权；不是已批准的功能契约
- 关联：ikzerok/worldline#26（CAP-09B）、ikzerok/worldline#24（已关闭，不提供游戏引擎适配器）

## 背景

CAP-09B 仍处于 `decision-gate`，目标写有稳定字符串 ID、源文修订、占位符、链接与上下文，但没有已批准的字符串身份或翻译保存生命周期。当前 `TextStmt` / `ChoiceStmt` 没有持久字符串 ID；源码位置、事件/场景名、选择顺序都会因移动或重排改变，不能单独充当稳定 ID。现有 `Project::content_baseline()` 绑定工作区当前内容；运行 fingerprint 则绑定可见原文及插值表达式，另有不同用途。两者不能被假定为同一个翻译修订号。

正文和选择中的显式链接具有目标 `TargetRef` 与可译显示文字；插值由 AST 表达式表示。当前语言只有一份作者原文，没有 locale 选择、翻译覆盖层或运行时语言回退契约。`Project` 有基线保护及可恢复保存事务，但跨文件文件系统原子性不作保证。

依赖 #24 已决定不选引擎、不制作引擎产物或适配器。这不决定翻译数据是否参与运行时输出，也不批准任何自动 ID 派生或自动选择内容策略。

## 建议的最小模型（待批准）

1. **字符串身份**：每个可翻译文本片段有作者显式、项目内唯一且不可变的 ID；ID 不由正文、路径、行号、事件/场景显示名或选择顺序派生。移动或改名时 ID 随片段保留。缺少 ID 的内容不进入导出；工具不自动创建、修复或重用 ID。源文哈希只表示导出时的修订，不表示身份。具体 ID 注记语法与迁移方式尚待批准。
2. **选择边界**：导出必须带调用者给出的明确 ID 白名单；没有默认“全部公开”、include 闭包或引用闭包。仅白名单片段及其必需的源文/受保护 token 数据可进入包。源引用使用相对路径及选中片段 ID，不写绝对路径。上下文（事件/场景/说话者、标题、前后片段）默认不导出；如要供译者查看，须作为每次请求明确选择的字段。显式链接只以不透明、不可编辑的受保护 token 表示；默认不导出目标资料、目标显示名或原始 `TargetRef`，也不自动扩展选择。
3. **交换格式与保护**：使用版本化 UTF-8 JSON。可编辑翻译只落在文本片段字段；插值表达式作为带稳定 token key 的不透明占位符，显式链接作为带稳定 token key 的不透明、不可编辑 token，链接显示文字作为可译文本字段。交换包不携带插值表达式或链接目标；源文 revision 匹配时，core 从当前 AST 取回受保护内容，revision 不匹配时只保留为待复核候选，不能把旧目标静默套到新源码。导回必须验证格式版本、全部必需 token 恰好保留一次、ID 唯一，不解析或执行译者提供的代码。保留换行和原始 Unicode 码点，不做规范化、转码猜测或 RTL 排版保证。
4. **过期与导回**：每条记录携带 source revision；源文变更时译文状态为“待复核”，不得静默当作当前译文。preview 只读，逐条报告缺译、重复/未知 ID、源文过期及 token 错误。apply 必须绑定 preview 的 Project `content_baseline`、交换包版本及 plan digest，并在保存前重算；任一不符整批零写入。目标是独立 locale sidecar，不改写 `.wl` 原文；保存沿用 Project 事务，不宣称多文件物理原子性。
5. **运行边界与 fingerprint**：此最小模型只交换和保存译文，不启用运行时 locale 选择、回退、混排或引擎导出。翻译 sidecar 和纯身份注记不改变运行 fingerprint；原文/表达式继续遵守现有 fingerprint 规则。若需要运行时 locale，必须另定切换/存档兼容契约。

## 仍需用户决定

实现前需授权或修订以下具体选择：

- **身份承载**：A. 在 `.wl` 可翻译节点旁声明显式 ID（移动时随节点走，需语言语法与格式迁移）；B. 独立注册表记录显式 ID 到节点的映射（源码较少改动，但映射如何在移动、拆分、复制及 ID 丢失时维护需另定）；C. 从稳定对象路径/内容生成 ID（不满足文本编辑及移动后的身份保证，不建议）。
- **翻译用途/存储**：A. 本提案的独立 locale sidecar，只提供导出、校验和保存，不影响 runtime；B. 导回覆盖 `.wl` 原文（不能保留多语言原文，且改动现有存档 fingerprint）；C. 运行时 locale overlay（需另定 locale 选择、缺译回退、输出链接、运行 fingerprint/save 兼容）。建议先选 A；B/C 不应从“翻译往返”一词推定。
- **过期导入**：A. 任何源文过期都拒绝整个 apply；B. 保留译文但存为 `needs_review`，明确不可作为当前译文消费；C. 接受旧译文为当前译文。建议采用 B，并禁止静默升级状态。
- **可见上下文/链接**：A. 严格最小包、无上下文且链接目标不透明（本提案）；B. 显示所选说话者/场景和链接目标显示名；C. 自动扩展选择以包含引用对象。B/C 会暴露选择外作者资料，若选用必须逐字段定义公开授权边界；建议仅按请求显式允许的字段导出，永不自动扩展。
- **占位符格式**：A. 结构化 JSON token（本提案，可重排但不可编辑/丢弃）；B. 在文本里使用约定的可见转义占位符。B 容易和原文冲突或被译者改写；建议 A。

以上任一授权都只决定本地化，不恢复 #24 已排除的引擎适配器。完成授权后，应先将获批选择写入 `spec/` 与 `spec/agent-protocol.md`，再实现 core Project API、CLI/RPC 与往返测试；在此之前不添加未批准的源码注记、持久格式、CLI/RPC 方法或运行语义。
