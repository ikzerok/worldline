# ADR-0004：本地检查点与受保护恢复

- 状态：已决定
- 关联：ikzerok/worldline#17（CAP-04C）

## 背景

会话撤销和可恢复保存事务不能提供跨会话历史。检查点必须保存当前工程缓冲及普通工作区文件的原始字节；恢复必须能检测过期预览、外部改动和损坏记录，并继续使用 Project 的分析结果报告受影响对象。

## 决定

- 桌面把完整检查点存入工作区私有目录 `.world/.checkpoints/v1/`。每个记录是单独目录，清单最后写入，校验完整后再从暂存名原子改名发布。负载按安全相对路径索引，以独立原始字节文件保存；记录包含版本、大小和 FNV-1a-64 校验，用于发现意外损坏，不作为防篡改签名。
- 浏览器复用相同公开 DTO、校验和配额，但存储仅在当前 WASM 模块生命周期内有效；重新挂载或重载后不承诺保留。记录按规范化 Project root 与 Project 的检查点会话 identity 分区；同一个 `/world` 挂载另一作品时，列举、删除与恢复不会访问前一会话的记录。浏览器本地保存快照可携带 identity 元数据以便恢复同一保存会话，但不携带检查点负载。宿主不得把历史写入下载包来冒充持久存储。
- 默认上限为 20 个记录、单条原始负载 64 MiB、历史原始负载合计 256 MiB、单条最多 4096 个文件；标签最多 120 个字符。宿主可传入更小的配额。大小按文件原始字节合计，不含清单与目录开销。达到任一上限时创建失败，不自动删除任何旧记录。用户显式删除记录后才释放配额；无法校验的完成记录仍占一个名额，且不能恢复。
- 检查点只在显式调用时创建，捕获当前 Project 缓冲与普通工作区文件；创建不保存作者文件、不推进保存基线、不改变运行指纹。检查点历史是本机工具状态，不进入工作区快照、工程导出或运行语义。
- 恢复先生成只读计划，列出新增、修改、删除文件及其当前/检查点大小，并由 core 对当前与检查点的完整源码集合各编译一次，列出与每个变更源码文件对应的对象。语法错误、无效源码字节或清单注册诊断会将对象影响标为不完整。
- 恢复计划绑定当前内容基线、完整工作区磁盘快照摘要和检查点摘要。执行时重新校验计划、只读状态、保存基线、记录完整性与磁盘摘要；任何检查失败都在写入前返回。成功时通过现有可恢复保存事务一次提交所需文件，再刷新 Project 缓冲。失败事务沿用现有事务恢复规则；本 ADR 不声称跨文件文件系统原子性。
- 工作区导出不包含 `.world/.checkpoints`。恢复会修改工作区文件，是明确的用户命令；创建和浏览不会。

## 后果

工程目录会在桌面本地保存受配额约束的历史。历史不会随工程导出、下载或上传；跨设备迁移不属于检查点能力。浏览器版本的检查点负载只在当前运行时保留，若要跨刷新保存，宿主需另行设计授权存储后端与配额契约；当前本地工程快照只保存会话 identity。

受损清单或负载不会显示为可恢复。完整但无法解析的记录仍可列出为不可用并显式删除；创建时它仍占容量，避免静默丢弃作者历史或错误绕过配额。
