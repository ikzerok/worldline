# v0.17 开发与验收合同

本轮同时交付确定性安全源码整理、世界对象焦点上下文、时间偏序解释，以及worldedit对应的焦点工作区、问题定位与自适应交互。版本0.17不增加新的语言语法；语言版本保持现有明确选择。所有语义与数据投影由core生成，编辑器、CLI和agent不得另行解释。

## 安全与兼容

- 确定性比较只规范无语义次序的集合，保留重复数量与所有真实语义顺序；不关闭安全移动等价保护
- 保存沿用可恢复journal事务，不能将物理跨文件写入称作单一原子操作
- 新只读上下文/时间见证以版本化合同提供；旧关系查询、运行与存档语义保持兼容
- 既有角色/实体改ID、冲突保护、状态、选择、重放、静态阅读交付均作为回归基线，不删除已有能力

## 完成闸门

两仓遵守AGENTS与源码行数限制；规范先行，行为/负例/跨入口合同测试齐全。确定性需同Project及独立进程重复；上下文需类型/来源/完整性验证；时间环需真实闭环与受阻下游验证；编辑器需真实作者任务、布局与键盘验证。所有平台/浏览器/IME/辅助技术结果分别标明实测与未测，仿真不冒充实机。

开发分支中的代码与测试可作WIP远端保存。最终配对必须固定core完整SHA，CI通过并核验后才合并。开发合并不等于已公开发布；公开release与tag另需单版确认。
