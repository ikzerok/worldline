# worldedit / worldline 0.25.0

## 当前源码结构与可信定位

在普通源文件页打开“本文件结构”，按名称、完整ID或类型筛选当前文件声明，确认同名对象的真实身份，再在同一源码缓冲精确定位与返回。Ctrl/Cmd+Shift+O、编辑菜单和任务命令均有入口。当前位置表示源码光标的声明归属，不是实际运行状态。

结构由core正式lexer/parser/AST及来源侧表产生，涵盖18类显式声明、完整嵌套scene路径与重复声明各自的来源。UI不另写解析器，也不存第二份可编辑正文。只读结构不改变语言、执行顺序、状态、运行指纹或保存格式；它不替代完整语义编译检查。

## 当前稿与可信范围

选择前重新核对精确正文、文件身份、活动集合、语言/能力、工程代次及磁盘保存基线。语法坏稿、外改冲突、未知能力或超预算时，旧列表不再可跳。语义重复仍保留可确认的语法声明；错误fragment中的scene不成为受支持的独立条目，不扩张语言合法性。

原始UTF-8范围保留中文、CRLF与注释边界；注释/空白不猜最近对象。源码编辑、撤销/重做、查询更新及IME组合有独立过期/焦点保护。返回只在原文版本一致时恢复旧选区与滚动，否则保留当前稿并说明原因。

硬预算为512KiB源码、16384物理行/单行字节、4096声明、64层及2MiB精确JSON投影。真实表达式的256 token/64层保护只在结构查询作用域生效，普通编译不增加限制。超限整份不可定位，不把截断结果当完整列表；源码仍保留。

## 排版与既有编辑流程

当前位置区保持固定空间，光标进入/离开声明不会挤动源码或破坏链接点击与返回滚动。临时结构列表左对齐并按层级缩进，名称为主，类型/ID/行号为辅；当前项与键盘选择分别标识，长中文可换行。收起后归还源码焦点与编辑面积。

本轮只覆盖普通源文件页，不重做书稿三种模式，不增加全工程符号重构或CLI/RPC遥控。实体移源、查找替换、书稿审阅、试玩、保存/撤销及读者公开选择保持。

## 兼容

产品0.25.0，默认语言1.9，最高既有显式语言1.13，无新DSL。0.24运行轨迹与运行检查点（ReplayTrace / ReplayCheckpoint）仍按既有runtime_version守卫拒绝跨版重放/比较，应重新录制。普通Story Save继续按格式、能力和指纹独立校验，不放宽守卫。升级前保留完整工程和原记录。
