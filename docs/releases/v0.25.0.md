# worldedit / worldline 0.25.0

## 当前源码结构与可信定位

本轮在同一语言源码编辑区中提供局部结构与可信跳转：查看当前文件的显式声明，区分同名对象，选择准确来源并返回原作者位置。core拥有结构、语言版本与来源范围；UI只消费只读投影，源码继续是唯一真源。

这是开发中的范围说明，不代表发布或验收已完成。具体支持类型、层级、预算、无效稿与过期规则以本轮正式规范为准；作者用法和验证结果将在实现完成后补齐。

## 兼容与边界

产品版本0.25.0，默认语言仍1.9，最高既有显式语言1.13。无新DSL，不更改执行顺序、状态或运行语义。本轮只覆盖普通源文件编辑区，既有书稿模式、实体移源、查找替换、保存/撤销和读者授权保留。

当前对象表示源码光标的结构归属，不表示实际演练状态。未保存/无效/外部变化/IME输入必须继续保留；不能显示新稿却跳转旧范围。源码结构导航不自动应用表单、保存或导出。

0.24运行轨迹与运行检查点（ReplayTrace / ReplayCheckpoint）按既有runtime_version守卫拒绝跨版重放/比较，应重新录制。普通Story Save按格式、能力与指纹独立校验；不放宽兼容守卫。升级前保留完整工程和原记录。

## 验收状态

尚在开发，未宣称新增实现通过测试。完成前要求core与editor默认/prototype完整回归、lint、原生与WASM构建、Linux原生闭环、精确配对PR/push/main CI和既有正式release门禁。

Linux原生合成输入与应用内中文复制粘贴不会冒充物理IME；Node/WASM不等于真实浏览器交互；Windows/macOS GUI、读屏及未完成项目会明确分列。
