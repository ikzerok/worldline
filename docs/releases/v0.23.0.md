# worldedit / worldline 0.23.0

## 逐处审阅后安全改稿

在同一篇故事里，相同文字可能是客观叙述，也可能是角色说错的话。0.23在既有查找与替换中加入精确的逐处取舍：阅读匹配附近原文，明确选中要修订的位置，核对前后差异后一次应用；导航中的当前项与将被替换的集合分别表达。

匹配、保护token、精确快照身份、Unicode上下文和替换事务都由core提供。查询、范围、选项、有效草稿或来源变化会使旧选择失效；伪造、重复、过期或受保护的选中项整批拒绝。预览与应用使用同一集合，取消不改稿，应用不保存，仍可一次撤销/重做。

结果以匹配附近的原文为主，来源路径、位置、保护与草稿状态分层。长行和同一行多处命中可独立判断，选择与执行计数明确；有界审阅区与必要操作分开，让小窗下的继续、应用和取消保持可达。

## 兼容与范围

产品版本为0.23.0；默认语言仍为1.9，最高既有显式版本1.13。没有新DSL、正则匹配或自然语言真假推理。既有全部替换、结构身份重构、书稿唯一缓冲、读者公开授权和工程导出保持。

上下文与选择元数据不新增运行语义，但正文替换本身仍可能改变运行指纹。0.22 trace/checkpoint按既有runtime_version守卫拒绝跨版重放或比较，应重新录制，不手改版本字段；普通Story Save继续按格式、语言能力与运行指纹独立校验。升级前保留完整工程与原记录。

搜索继续最多10000处命中的硬限，超限明确报错。每处上下文有界，超长匹配、病态字素簇和前后省略如实标明，片段不冒充完整原文。全部已知命中应在该限额内可访问；分页显示量与实际选择量分别说明。

完整本地检查和原生验收在最终候选核验后记录。正式发行由原工作流在双仓精确main及CI门禁通过后构建并核验六个资产；工作分支不等于已发行。Windows/Web构建、Linux原生AI合成输入、Node/WASM、真实浏览器、物理IME和读屏的覆盖必须分别说明。
