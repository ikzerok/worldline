# worldedit / worldline 0.26.0

## 当前源码行列定位

普通“源文件”页新增真实光标行列提示。点击位置、按Ctrl+G（macOS为Control+G）、编辑菜单或任务命令，都可输入物理行号或行:列，核对当前文件和目标原文预览，再准确定位并继续编辑。Esc只取消，成功定位才记录可返回的作者位置。

位置与声明归属分别显示；空白、注释和未完成语法仍有文本坐标。文件名左对齐，标题与位置入口占用固定空间。长行预览自动让当前目标可见，后续手动滚动不会被持续抢回；新目标不沿用旧滚轮余量。

## 一个确定的文本坐标

行列均从1开始，列按Unicode标量计数；中文、ASCII、Tab各计1，组合标记分别计数，不把字节、字素和视觉宽度混用。LF与CRLF各为一个物理换行，空文件1:1、末尾空行与行尾插入点合法，不落在UTF-8字节或CRLF中间。软换行不改变物理行号。

请求只在整个输入两端去空白，内部空白、非ASCII数字、零、负数、正号、溢出、缺项、多冒号与超界明确拒绝，不静默夹到别处。core给出目标附近的真实上下文、范围和两端省略标记，UI不另写坐标或语言解释。

单份正文2MiB、65,536物理行、原始请求128字节，预览最多240个Unicode标量；上限含边界。超限只使本定位工具不可用，原稿继续保留，不扩大语言限制。

## 当前稿与保护

预览绑定精确正文、规范路径、工作区根、内容基线、刷新代次与编译选项。确认时重新核对全部公开预览和磁盘保护，篡改、过期、外部冲突、未知清单/能力、来源越界与未完成保存事务拒绝。坏DSL不调用旧AST猜测坐标；已跟踪归档源码可纯文本定位，不因此激活。

导航不应用表单、不保存、不执行故事、不改变运行指纹。返回只在原文仍一致时恢复旧选区与滚动，否则保留当前稿并说明。输入法组合、同帧查询变更、查找/结构/命令层级与真实来源更新有独立保护。

本轮限普通源码；本文件结构、查找替换、书稿、实体移源、试玩、保存/撤销和读者公开授权保持。不新增书签、折叠、多光标、跨项目跳转或CLI/RPC遥控。

## 真实平台边界

实际Linux原生窗口1188×848。全局最小1040×660未变，但本环境未能把真实窗口改至该尺寸；1040×660及800×600、亮暗主题、16/28字号、长行/长文件名是合成App事件与几何验证，800×600不是原生。

中文应用内复制粘贴不等于物理IME；物理输入法、读屏、可靠原生鼠标、Windows/macOS GUI与高DPI未验。两套WASM经Node模块有效性检查，不代表真实浏览器worldedit GUI或故事运行。Emoji坐标测试不保证所有字形可见。

正式发行仍以精确配对提交的PR/push与main CI、原发布工作流及六公开资产校验为门禁。正式配对SHA、CI和构建信息见发行资产release-pair.json，下载后核对SHA256SUMS.txt；本地通过不代替这些门禁。
