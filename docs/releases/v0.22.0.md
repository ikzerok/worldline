# worldedit / worldline 0.22.0

## 可信的全分支作者审稿

书稿当前章节和整书阅读保留条件、选择与场景层次，台词显示人物姓名及稳定身份，并可在核验当前稿后逐段回到真实源码。长中文正文和链接沿同一排版流显示，结构提示与正文分层；未应用输入、旧快照、外部冲突或预算失败有明确状态。

核心投影来自正式AST，不执行条件、不消耗随机数、不展开调用、不把所有静态分支当作一条实际路线。CLI `manuscript-review` 与RPC `manuscript.review`使用同一只读契约。旧静态读者站的授权与输出保持。

- [核心与CLI指南](https://github.com/ikzerok/worldline/blob/main/docs/manuscript-review.md)

## 兼容与范围

产品版本为0.22.0；默认语言仍为1.9，最高既有显式版本1.13，无新DSL。静态作者审稿不改变运行指纹、Save或Trace形状。0.21 trace/checkpoint仍受既有runtime_version守卫保护，应重新录制；普通Story Save继续按格式、语言能力和运行指纹独立检查。

源码合计16MiB、单投影10000节点、深度64、JSON结果1MiB；超限明确拒绝，不提供假完整稿。整书逐章保留成功或失败状态，不把不可预览的章节默默省略。

本版不声称路径穷举、自然语言一致性证明、真实路线读稿导出或在线共同编辑。Windows/Web发行构建与自动化测试不能代替各平台原生交互验收；Linux原生AI模拟输入、Node/WASM、实际浏览器、物理IME和读屏的验证范围必须分别说明。完整发行门禁和具体已知限制以随版验收记录为准。
