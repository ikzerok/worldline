## 规则与使用处的可信上下文

core在同一编译快照中建立有界静态索引，区分规则调用、片段调用、全局读取和全局写入，并给出使用语境与真实源位置。局部/参数及静态身份参数不冒充全局读取；重复同一行仍保留独立出现处。既有world-context默认投影不变，显式include_executable或新kind才启用。无效或歧义来源、缺源及预算耗尽明确不完整，不能把零条记录宣称为无使用处。

## 真实重放后的Markdown作者审阅

一条轨迹必须在当前已应用稿上经过有界真实重放，才把匹配的实际正文、选择、说话者与当前源码位置写入报告。篡改输出不会进入已验证正文；记录中的伪标签或行号不替代真实身份。报告明确入口/检查点、继承范围、seed、源指纹与清单、已验证选择和完成/中止状态。未访问内容只是未探索。

作者必须明确复制或导出；默认不包含变量名/值、任意状态JSON、局部值、资料元数据、作者备注或附件，不扩大静态读者站的公开授权。正文、选择和源码文件名仍可能含私人内容。原始trace及存档可能含更多运行数据，分享前需独立核对。

## 已完成的核心本地验证与边界

Linux workspace完整测试1455通过、0失败、8忽略，strict clippy与release构建通过。实际release CLI/RPC另有89项断言通过：静态上下文、两条完整路线、报告来源与隐私、篡改/部分/检查点/预算边界、旧存档及完整工程换路径复现。专项与全套按各自范围记录，不相加宣称独立测试总量。

合成无跃迁片段DAG：旧版20层一次实测约1706ms，新版20/24/32层各三次约3–6ms，均含CLI启动、IO、编译与JSON输出。此结果只说明该反例已修复，不是通用工程提速承诺。含真实跃迁的极端DAG明确A231；未触限的旧图oracle逐字段完全一致。

本轮不新增DSL，默认语言1.9、最高显式1.13保持。实际0.27普通暂停Story Save在同源码0.28继续成功；0.27的ReplayTrace/ReplayCheckpoint仍按既有runtime_version守卫拒绝，应重新录制。该样本不能推断所有历史存档兼容。

构建、Node/WASM模块检查与合成输入不能替代浏览器GUI、物理IME、读屏、Windows/macOS原生交互或高DPI验收。正式发行继续受固定提交CI与配对发布门禁约束，资产身份以release-pair.json与SHA256SUMS.txt核对。
