# worldedit / worldline 0.28.0

本页为候选版本范围，实现与验证中，尚未宣称发行。正式发行需完成本地原生与WASM、默认与prototype测试及lint、双仓配对CI、main CI和原发行工作流，再核验实际公开资产。

## 作者依赖与试玩审阅

- [静态可执行依赖](https://github.com/ikzerok/worldline/blob/main/spec/executable-context.md)：规则调用、片段调用与全局变量读写有类型、语境及真实来源；不作为已执行动作
- [可读试玩审阅](https://github.com/ikzerok/worldline/blob/main/spec/playthrough-report.md)：传入轨迹必须经当前稿有界验证后才生成作者副本，明确起点、继承区间、完成/中止状态及来源

审阅记录可能含作品中的私密叙事内容，只由作者明确导出；不扩大静态读者站的公开选择，不自动包含变量、附件或整个工程。复制/保存文本不改变当前试玩、随机流或作者源码。

## 地图往返与清晰汇聚

资料、源码与地图间的作者位置采用有效身份验证，返回只导航，不写入旧对象。地图名称与标记名称优先显示，稳定ID用于消歧。时间线和事件图的同端点连线仅作视觉分组，保留全部原始边、条件、标签和来源。

## 共享片段分析

静态图分析以保守摘要识别无跃迁共享片段，减少重复调用展开。真实跃迁的上下文、来源与循环诊断继续保留；具体分析预算及性能验收以[语义规范](https://github.com/ikzerok/worldline/blob/main/spec/semantics.md)和最终验收记录为准。

## 兼容与验证范围

本轮工具版本0.28.0，不新增DSL。默认语言1.9与最高显式1.13保持。0.27的ReplayTrace/ReplayCheckpoint按既有runtime_version守卫拒绝跨版本重放或报告，应重新录制。普通Story Save继续按格式、能力与指纹独立校验，不据此宣称全部历史存档兼容。

本地全量、实际作者路径、官方CI和六资产验证结果在完成后填入；当前不以计划代替完成。Node/WASM模块检查不等于浏览器GUI，Linux合成按键不等于物理IME、读屏、Windows/macOS GUI或高DPI测试。

[正式发行列表](https://github.com/ikzerok/worldedit/releases)中的release-pair.json记录精确双仓身份，SHA256SUMS.txt用于对应公开资产校验；候选尚未有本版资产。
