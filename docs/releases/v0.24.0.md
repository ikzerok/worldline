# worldedit / worldline 0.24.0

## 把一条实体资料安全整理到另一份源码

当一份设定文件越来越长，作者可以把其中一个地点、组织或物件的entity声明整理到另一份已有活动源码。0.24先显示同一对象的稳定身份、旧/新来源与两侧精确原文，确认后一次应用；引用继续指向同一个实体，来源导航跟随真实位置。

core负责声明边界、原字节、静态资料与正式引用等价、加载顺序及运行指纹证明。独立前置注释、相邻声明和分隔内容不会被猜测为所属资料。无法证明的资源路径/字节、注册语义、过期计划、外部变更、非活动源与未知能力明确阻止提交。同文件目标给出零变化结果。

应用只改变两个源码缓冲，可一次撤销/重做，保存仍使用既有可恢复事务。未应用表单或正文不会被暗中提交；界面先保留输入并要求处理。移源不自动保存，作者能区分已应用未保存与已保存。

## 完整工程备份的数据保全

修复显式source_sets工程在完整工程导出中遗漏已跟踪非活动/归档源码的问题。导出保留这些稿件原始字节及清单的active/archived身份，重新打开仍按原活动集合编译；不把归档源码自动激活。这是完整工程备份路径的修复，不改变公开HTML读者包的显式选择、隐私授权或内部工具状态的排除边界。

## 兼容与范围

产品版本0.24.0，默认语言仍为1.9，最高既有显式语言1.13。没有新DSL或第二份世界资料；这不是人物、事件、片段、目录、资源或批量对象迁移。原整文件移动、逐处审阅替换、书稿审阅、试玩、资料导入与读者授权保持。

同版本内成功实体移源必须保持运行指纹，不改变分支行为或state所属身份。0.23 trace/checkpoint仍按既有runtime_version守卫拒绝跨版重放/比较，应重新录制；普通Story Save按格式、能力和指纹独立校验，不删改兼容检查。升级前保留完整工程和原记录。

本地完整验收：core 1315通过、8个既有显式性能用例忽略；editor默认772通过/7忽略，prototype 787通过/8忽略。两仓格式、600行检查、lint、原生与WASM构建通过；独立CLI/双进程RPC验收147项断言通过。完整工程导出回归覆盖非活动/归档原字节、清单状态、磁盘重开、越界链接拒绝及公开选择不变。

Linux原生以AI合成输入实际完成：选择活动目标、精确两侧预览、应用、一次撤销/重做、保存、关闭重开与稳定ID定位新来源。同文件无变化与取消保留原稿也已验收。原生测试发现并修复IME结束单帧丢失目标焦点的问题；组合/结束帧抑制动作但保留焦点，新预览一次滚动到可读位置，均有完整App回归。
